# 安装 TavernLens

1. 退出 HDT。
2. 将完整 `TavernLens` 文件夹放入 `%APPDATA%\HearthstoneDeckTracker\Plugins`。
3. 启动 HDT，在“设置 → 插件”中启用 **TavernLens · 酒馆透镜**。
4. 在下一次英雄或饰品选择时查看统计。

保留同目录的 `TavernLensBackend.exe` 和 `_internal`，无需安装 Python。

插件设置可调整分段、时间范围、大小和位置。双人模式暂只提供英雄统计。

项目：https://github.com/OpenBigc/TavernLens
